# WebAble – Bachelor Thesis Project

This repository contains **WebAble**, a browser extension developed as part of a bachelor thesis project focused on supporting developers in implementing web accessibility principles more easily.

Additionally, the repository includes a separate test website used for conducting user tests and evaluating the extension in realistic accessibility scenarios.

---

# Repository Structure

```text
.
├── WebAble_Extension/   # Chrome browser extension (WebAble)
├── Test_Website/        # Website used for user testing
└── README.md
```

---

# About the Project

The goal of this project is to explore how browser-based tools can support developers in identifying and implementing accessibility principles during web development.

The project consists of two main parts:

## 1. WebAble Browser Extension

The extension is designed to assist developers by providing useful information about fundamental accessibility principles directly within the browser environment.

Features may include:
- Accessibility guidance
- Suggested tools and websites

## 2. User Testing Website

The test website is used during user evaluations of the extension.

It contains different accessibility issues and interface elements that allow participants to test and interact with the extension in a controlled environment.

```bash
git clone https://github.com/JuliaHummer/BachelorThesis-WebAble.git
```

---

# Running the Browser Extension

1. Open Google Chrome
2. Navigate to:

```text
chrome://extensions
```

3. Enable **Developer Mode**
4. Click **Load unpacked**
5. Select the `WebAble_Extension` folder

The extension should now be available in Chrome.

---

# Running the User Testing Website

Simply open the `main.html` file inside the `Test_Website` folder in your browser.
